# GPT 网页端生图规则

## 唯一路由

GPT 网页端是唯一生图渠道。分镜首帧、合理尾帧和完整封面均由智能体在已登录的 ChatGPT 网页端提交请求、等待生成并下载原图。不得切换到本机 Codex 生图、第三方生图 API 或 DeepSeek 生图，也不得并行请求多个渠道。

遇到登录、验证码、二次验证、订阅限制或网页不可控时，返回 `image-failed` 并保存简短原因；不得要求用户提供账号密码，不得读取或转存登录凭据。

## 单次外部动作

运行器返回 `GPT_WEB_IMAGE_REQUIRED` 后，只执行一次完整浏览器动作：

1. 读取动作 JSON 中的图片用途、提示词、参考图和目标路径。
2. 在 GPT 网页端上传所需参考图并提交完整提示词。
3. 等待生成结束，使用网页提供的原图下载功能保存结果；不得用截图或预览缩略图代替。
4. 调用 `pipeline_runner.py accept-image` 提交下载文件；随后再次调用 `pipeline_runner.py next`。

网页动作之外不把对话全文、截图分析或完整日志送入 DeepSeek。需要重试时由运行器的失败计数和策略决定，智能体不得自行无限重试。

## 请求约束

每次请求至少包含：视频 ID、图片用途、产品名称、参考图、完整提示词、必须保持项、禁止出现项、9:16 画幅和输出目标。合理尾帧必须以上一张已晋升的分镜图为主要参考，并表现同一镜头自然向前发展；尾帧不得复用首帧文件。

完整封面提示词必须包含已确认的封面标题，并要求 GPT 在一次生成中完成画面、版式和标题。禁止先生成无字底图后再用代码、脚本、Canvas、SVG、HTML/CSS 或其他程序叠字、改字。

## 无图片审核策略

按用户已确认的自动生产策略：

- 不进行人工图片审核。
- 不调用模型进行二次视觉审核。
- 不判断产品相似度、人物动作、文字准确性或构图美观度后再决定是否晋升。
- GPT 网页端下载结果通过本地免费技术检查后，脚本自动晋升并直接进入下一步。

此策略只省略图片内容审核，不省略文件安全与视频付费闸门。最终视频仍由用户人工验收。

## 本地免费技术检查

`pipeline_runner.py accept-image` 必须调用确定性脚本检查：

- 文件存在、非空且能解码为真实图片，不是 HTML、错误响应、截图占位或损坏文件；
- 画幅为 9:16；
- 原图为 `1152×2048` 时允许等比归一化为 `2160×3840`，不得拉伸、裁切、补画、重构版式或新增文字；
- 其他尺寸只有能无语义变化地等比归一化到 `2160×3840` 时才可处理，否则返回失败；
- 计算并记录原图与归一化结果的 SHA-256；
- 候选文件位于当前任务 `_工作文件/生成过程`；
- 尾帧 SHA-256 必须与正式分镜图不同。

检查通过后，脚本以原子方式写入对应一级正式文件：`分镜图.png`、`尾帧图.png` 或 `封面图.png`，记录自动授权验收事件和 SHA-256，然后继续状态机。检查失败时不得晋升，也不得触发视频付费提交。

## 完成条件

生图节点在以下条件同时满足时完成：原图已下载、免费技术检查通过、目标 4K 文件已落盘、SHA-256 已记录、尾帧与首帧哈希不同、正式文件已原子晋升。除网页生图本身外，这些步骤不调用 DeepSeek 或其他模型。
