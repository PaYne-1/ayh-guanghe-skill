# 视频单镜头与完整口播规则 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把“一镜到底、缓慢连续运镜、15秒自然完整口播”落实为产品视频技能的生成合同、提交前校验和自动验收硬规则。

**Architecture:** 规则文本负责指导策划、提示词和验收；现有 `workflow_cli.py` 只增加轻量、确定性的提交前门禁，不开发应用。汉字口播预算采用最多49个汉字，相当于约3.5字/秒并预留约1秒自然停顿；超限时由策划步骤自动精简后重新校验。

**Tech Stack:** Markdown 技能规则、Python 3 标准库、pytest。

## Global Constraints

- 15秒视频必须一镜到底，禁止切镜、跳切、转场和景别突变。
- 允许缓慢、连续、平稳运镜，但人物完整度、轮椅角度、主体构图、曝光、白平衡、亮度和色温必须保持分镜基准。
- 口播必须按自然聊天语速完整结束；超限时自动精简，但保留唯一卖点、使用改善和结尾了解引导。
- 任一硬规则失败，整条视频自动判为不合格。
- 不开发新应用，不改变15秒、默认分辨率、预算或付费授权规则。
- 仓库技能副本与 `C:\Users\Administrator\.agents\skills\product-video-pipeline` 已安装副本保持一致。

```python
if not any(term in video_prompt for term in SINGLE_SHOT_TERMS):
    issues.append("shot.single_required")
if not any(term in video_prompt for term in NO_CUT_TERMS):
    issues.append("shot.cut_forbidden")
if not any(term in video_prompt for term in SMOOTH_CAMERA_TERMS):
    issues.append("camera.smooth_continuous_required")
if not any(term in video_prompt for term in COMPLETE_NARRATION_TERMS):
    issues.append("narration.complete_required")
dialogue_han = sum(_han_count(str(segment.get("dialogue", ""))) for segment in segments if isinstance(segment, dict))
if dialogue_han > NARRATION_HAN_BUDGET:
    issues.append("narration.too_long")
```
