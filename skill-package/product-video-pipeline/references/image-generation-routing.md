# 生图渠道路由规则

## 确定性路由

```text
启动必选渠道 -> 批次批准并锁定 -> 签发对应外部动作
-> 外部渠道生成并下载 -> accept-image -> 统一本地技术检查
-> 自动晋升 -> 下一节点
```

启动时必须选择 `GPT 网页端` 或 `第三方 API`。`approve-start` 后选择写入已批准清单，渠道在批次内锁定；已锁定生图渠道禁止自动切换，发生错误也不得回退到另一个渠道。若需切换，必须重新启动并新建批次。

`GPT 网页端` 对应 `GPT_WEB_IMAGE_REQUIRED`：这是当前已登录 ChatGPT 浏览器会话中的人工浏览器操作，上传参考图、提交提示词、等待生成并下载原图。`gpt_web` 禁止服务器端 OpenAI API 调用。

`第三方 API` 对应 `THIRD_PARTY_IMAGE_REQUIRED`：这是宿主或 API 适配器操作，使用动作中提供的 `api_name`、`base_url`、`model`、`api_key_env`、`unit_price_yuan`、`batch_budget_yuan` 非密钥配置生成并下载原图。适配器从 `api_key_env` 读取安全环境变量，绝不把密钥写入动作、状态、日志或聊天内容。

遇到登录、验证码、二次验证、订阅限制、API 配置、鉴权或服务故障时，返回 `image-failed` 并保存简短原因；不得要求用户提供账号密码，不得读取或转存登录凭据或 API 密钥。

第三方 API 失败必须带 `image-failed --submission-state not_sent|sent|unknown`；默认 `unknown`。`not_sent` 会释放该次图片 API 费用保留，因此运行器可按已批准预算重新签发动作；`sent` 会将该次费用计入已用预算；`unknown` 保持预算占用并阻止自动重试，运行器会阻断批次，等待操作员核实外部提交结果。GPT 网页端不依赖提交状态，使用相同失败原因重放时仍保持原有幂等性。

## 单次外部动作

运行器每次只返回一个已保留的动作。按动作类型执行一次对应外部动作：

1. 读取动作 JSON 中的图片用途、提示词、参考图和目标路径。
2. `GPT_WEB_IMAGE_REQUIRED` 在 GPT 网页端上传所需参考图并提交完整提示词；`THIRD_PARTY_IMAGE_REQUIRED` 由宿主/API 适配器按封存配置提交。
3. 等待生成结束，下载原图保存为动作的目标路径；不得用截图或预览缩略图代替。
4. 两条路径都调用 `pipeline_runner.py accept-image --batch "批次目录" --video-id "视频ID" --artifact "图片产出名" --source "原图路径" --action-id "动作ID"` 提交下载文件；随后再次调用 `pipeline_runner.py next`。

网页动作之外不把对话全文、截图分析或完整日志送入 DeepSeek。需要重试时由运行器的失败计数和策略决定，智能体不得自行无限重试。

`IMAGE_FAILURE_RECORDED` 只是失败通知，不是新的生图授权。再次调用 `next` 后，只有获得带新 `action_id` 的同一渠道 `GPT_WEB_IMAGE_REQUIRED` 或 `THIRD_PARTY_IMAGE_REQUIRED` 才能重试。已接收动作重复回传同一结果不增加次数，恢复中断的已保留动作时不重复生成。

## 请求约束

每次请求至少包含：视频 ID、图片用途、产品名称、参考图、完整提示词、必须保持项、禁止出现项、9:16 画幅和输出目标。合理尾帧必须以上一张已晋升的分镜图为主要参考，并表现同一镜头自然向前发展；尾帧不得复用首帧文件。

完整封面提示词必须包含已确认的封面标题，并要求已锁定生图渠道在一次生成中完成画面、版式和标题。禁止先生成无字底图后再用代码、脚本、Canvas、SVG、HTML/CSS 或其他程序叠字、改字。

## 无图片审核策略

按用户已确认的自动生产策略：

- 不进行人工图片审核。
- 不进行模型视觉审核。
- 不判断产品相似度、人物动作、文字准确性或构图美观度后再决定是否晋升。
- 两条渠道下载结果通过同一套本地免费技术检查后，脚本自动晋升并直接进入下一步。

此策略只省略图片内容审核，不省略文件安全与视频付费闸门。最终视频仍由用户人工验收。

## 本地免费技术检查

`pipeline_runner.py accept-image` 必须调用确定性脚本检查：

- 文件存在、非空且能解码为真实图片，不是 HTML、错误响应、截图占位或损坏文件；
- 画幅为 9:16；
- 原图为 `1152×2048` 时允许等比归一化为 `2160×3840`，不得拉伸、裁切、补画、重构版式或新增文字；
- 其他尺寸只有能无语义变化地等比归一化到 `2160×3840` 时才可处理，否则返回失败；
- 计算并记录原图与归一化结果的 SHA-256；
- 候选文件位于当前任务 `_工作文件/生成过程`；
- 尾帧 SHA-256 必须与正式分镜图不同。

检查通过后，脚本以原子方式写入对应一级正式文件：`分镜图.png`、`尾帧图.png` 或 `封面图.png`，记录自动授权验收事件和 SHA-256，然后继续状态机。检查失败时不得晋升，也不得触发视频付费提交。

## 完成条件

生图节点在以下条件同时满足时完成：原图已下载、免费技术检查通过、目标 4K 文件已落盘、SHA-256 已记录、尾帧与首帧哈希不同、正式文件已原子晋升。除对应外部生图动作本身外，这些步骤不调用 DeepSeek 或其他模型。
