# 产品视频技能 API 永久配置设计

## 目标

为 `product-video-pipeline` 增加独立触发词 `配置api`。该触发词只启动 API 配置向导，不启动产品视频批次，不扫描产品目录，不生成媒体，也不执行付费调用。已保存配置持续复用，只有用户再次说出 `配置api` 并明确选择更换时才覆盖。

## API 清单

1. **AutoDL.Art 视频 API（必需）**
   - `AUTODL_API_KEY`
   - `AUTODL_AUTH_SCHEME`：`bearer` 或 `raw`
   - 提交端点、查询端点和工作流 ID 继续由技能维护，正常情况下不要求用户填写。
2. **第三方生图 API（可选）**
   - 服务商名称、`base_url`、模型名称、API Key。
   - 只有用户在视频启动清单中选择“第三方 API 生图”时才是运行必需项。
3. **第三方文本生成 API（可选）**
   - 服务商名称、`base_url`、模型名称、API Key。
   - 默认使用当前 Agent 原生文本能力时不需要配置。

本机 Codex 生图和 ChatGPT 网页端生图依赖登录状态，不需要 API Key，不列入 API 配置。

## 触发与交互

用户说 `配置api` 后，技能必须：

1. 显示三类 API 的用途、必需性及当前状态；只显示“未配置/已配置”和密钥末四位，不回显完整密钥。
2. 询问本次要配置或更换 AutoDL、第三方生图、第三方文本中的哪一项。
3. 先收集非敏感字段；完整 API Key 通过本机交互式终端隐藏输入，不要求用户粘贴到聊天。
4. 写入 Windows 当前用户级永久环境变量。配置保持有效，直至用户再次触发并明确更换。
5. 做格式检查；服务商存在明确且不扣费的鉴权检查时，再做联网验证。不得用生成图片、生成视频或其他计费请求验证密钥。
6. 报告配置结果、保存范围、验证结果和密钥末四位。不得把完整密钥写入技能文件、项目文件、命令行参数、日志或聊天。

`配置api` 不得继承为产品视频的付费授权。配置成功也不表示用户批准任何付费生图或视频提交。

## 永久存储

采用 Windows 当前用户环境变量，兼容现有脚本及不同 Agent：

| 类型 | 环境变量 |
|---|---|
| AutoDL | `AUTODL_API_KEY`、`AUTODL_AUTH_SCHEME` |
| 第三方生图 | `PRODUCT_VIDEO_IMAGE_API_PROVIDER`、`PRODUCT_VIDEO_IMAGE_API_BASE_URL`、`PRODUCT_VIDEO_IMAGE_API_MODEL`、`PRODUCT_VIDEO_IMAGE_API_KEY` |
| 第三方文本 | `PRODUCT_VIDEO_TEXT_API_PROVIDER`、`PRODUCT_VIDEO_TEXT_API_BASE_URL`、`PRODUCT_VIDEO_TEXT_API_MODEL`、`PRODUCT_VIDEO_TEXT_API_KEY` |

配置工具从 Windows 用户环境读取状态，使当前 Codex 会话也能看到刚保存的值；不依赖应用重启。密钥不得保存到 `.env`、JSON、Markdown 或技能包。

## 更换与失败处理

- 只覆盖用户本次明确选择的 API 类型，其他配置保持不变。
- 新值完成基本格式检查前，不覆盖旧值。
- 如果无计费验证失败，保留旧配置并报告原因；不得清空旧密钥。
- 服务商不提供安全验证接口时，明确标记“已保存，未联网验证”，不得伪造验证成功。
- 任何输出和异常都必须屏蔽密钥，仅允许显示末四位。

## 实现范围

- 更新技能触发说明和路由，区分“产品视频启动”与“API 配置”。
- 新增 API 配置参考文档。
- 新增本地配置工具，支持状态查看及隐藏输入配置。
- 更新 AutoDL 客户端，使其在当前进程环境缺少变量时读取 Windows 用户环境中的永久配置。
- 为触发文案、变量映射、遮罩输出、永久写入、旧值保护和非付费边界增加离线自检。
- 版本号递增，并同步已安装技能与仓库中的技能源包；不覆盖工作区中无关改动。

## 验收标准

- `配置api` 能单独触发配置向导，不展示产品视频启动清单。
- 状态页准确列出必需与可选 API，且不泄露完整密钥。
- 隐藏输入后，配置写入 Windows 当前用户范围，并能被新进程和当前技能工具读取。
- 未再次触发并明确更换时，技能不重复询问 API。
- 配置和验证过程不产生付费任务。
- 自检、Python 语法检查和技能结构校验全部通过。
