# product-video-pipeline 1.8.7

- 不强制4K：按渠道支持的原生分辨率请求和验收，保留9:16竖屏（允许1像素取整误差），禁止本地放大、拉伸、裁剪。
- 请求、提示词、图片接收和视频提交校验统一移除2160×3840硬限制。旧policy的target_width/target_height仅保留摘要兼容，不再作为尺寸要求。
- 视频等待改单次GET查询，单次超时20秒；返回服务端状态、等待时间及下一次查询间隔，持久化冷却避免频繁查询。
- 已有task_id只查询不重新POST；鉴权等终止性查询错误或连续5次网络错误会明确提示核对已有任务，不假装仍在生成。
- 这是响应与进度反馈改善，不承诺服务商生成加速；没有使用真实API进行付费测试。
