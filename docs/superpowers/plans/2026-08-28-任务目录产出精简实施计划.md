# 产品视频任务目录产出精简 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让每条产品视频任务的第一级只保留五项最终产出和 `_工作文件`，并安全迁移现有任务而不删除、覆盖或重复提交。

**Architecture:** 在 `workflow_cli.py` 中集中定义任务目录协议、兼容读取和迁移能力，所有确定性写入通过该协议选择目标路径。新任务直接按新结构创建，旧任务读取时回退旧路径；独立 `organize` 子命令按文件名和目录名分类现有文件，并在移动前检查目标冲突。

**Tech Stack:** Python 3、`pathlib`、`argparse`、标准库文件哈希、pytest、Markdown Agent Skill 规则。

## Global Constraints

- 单条任务第一级只允许 `视频.mp4`、`封面图.png`、`发布正文.md`、`标题.txt`、`分镜图.png` 和 `_工作文件`。
- 工作目录固定包含 `任务状态`、`生成过程`、`验收记录`、`历史版本` 四类。
- 不能明确分类的非交付文件默认归入 `_工作文件/生成过程`。
- 不删除任何已有文件，不覆盖同名异内容文件，不重新提交任何付费任务。
- 新路径优先读取，旧的第一级路径仅作为未迁移任务的兼容回退。
- 批次级目录结构不变。
