# 产品视频技能 API 优先接入设计

## 目标

让 `product-video-pipeline` 在安装完成后优先引导用户接入 AutoDL API。只要 API 尚未配置或尚未验证，技能就不得进入产品扫描、批次初始化、内容策划或付费提交流程。

## 用户流程

1. 安装技能包后，安装说明要求立即运行 API 配置向导。
2. 技能每次被调用时先检查 API 接入状态，形成跨平台兜底。
3. 未检测到 `AUTODL_API_KEY` 时，第一条业务回复只处理 API 接入：说明密钥获取位置、安全配置方法和下一步验证方式，不询问产品路径。
4. 已检测到密钥但未验证时，先执行不扣费的配置检查和 dry-run；验证通过后记录本地就绪状态。
5. API 就绪后，技能才进入产品路径、卖点、数量、模式、分辨率和预算的启动确认流程。
6. 正式提交仍需独立的费用确认，API 已接入不等于授权付费。

## 实现范围

- 在 `SKILL.md` 增加“节点 0：API 接入门禁”，并把它置于现有启动确认流程之前。
- 在 `references/install.md` 增加安装后立即配置步骤。
- 新增便携配置检查脚本。脚本只检查环境变量、鉴权格式和客户端基本配置；不得输出密钥，不得产生付费请求。
- 在 `references/startup-checklist.md` 明确：API 未就绪时暂停，不展示产品批次确认单。
- 更新自检与自动测试，覆盖未配置、已配置、密钥不泄露和 dry-run 不扣费四类行为。

## 安全与状态

- API Key 只从 `AUTODL_API_KEY` 环境变量读取。
- 鉴权方式从 `AUTODL_AUTH_SCHEME` 读取，允许 `raw` 或 `bearer`，默认按当前官方说明建议 `raw`。
- 聊天中不得要求用户粘贴完整密钥；优先指导用户通过隐藏输入或系统环境变量配置。
- 本地就绪状态不能包含密钥，只记录检查时间、鉴权方式和 dry-run 结果。
- 连通性检查如需联网，只允许无计费端点；无法确认无计费时仅做本地检查和 dry-run。

## 错误处理

- 未配置密钥：显示接入指导并停止业务流程。
- 鉴权方式非法：提示允许值，不读取产品素材。
- dry-run 失败：报告具体配置错误，不进入批次流程。
- API 已配置但实时价格或会员状态未知：进入启动确认时继续查询或向用户确认，但不得据此自动付费。

## 验收标准

- 新安装后首次调用，技能首先提醒接入 API。
- 未提供 API 时，不再询问产品路径或创建批次。
- API Key 不出现在日志、JSON、异常或聊天回复中。
- dry-run 明确标记为不联网、不扣费。
- API 就绪后，原有产品视频 11 节点流程保持不变。
- 所有现有测试和新增测试通过。
