# 分镜图生成路由（强制规则）

分镜图不得调用当前智能体自身的原生生图能力。无论当前技能由 Codex、WorkBuddy、Hermes 或其他智能体执行，都必须按照以下固定顺序生成：

1. 本机 Codex 界面
2. ChatGPT 网页端
3. 已配置并获准使用的第三方生图 API

不得跳级，不得改变优先顺序。

## 1. 本机 Codex 界面

当前智能体具备 Windows 应用控制能力时，必须首先操作本机已登录的 Codex：

- 新建独立生图任务，避免污染其他任务上下文。
- 上传选定的产品主参考图和辅助参考图。
- 提交完整分镜提示词、目标尺寸 `2160×3840` 和画幅 `9:16`。
- 等待生成完成并取得实际原始图片文件。
- 将图片复制到 `_工作文件/生成过程/分镜候选.png`。
- 仅看到界面预览不算完成，必须取得本地文件。

本机 Codex 未安装、未登录、无法操作、生成报错、未产生图片文件或图片验收不合格时，进入 ChatGPT 网页端。

## 2. ChatGPT 网页端

使用浏览器控制能力操作本机已登录的 ChatGPT：

- 使用独立对话完成本条分镜生成。
- 上传与 Codex 节点相同的产品参考图。
- 提交相同的完整提示词、尺寸和画幅要求。
- 下载原始图片，不得使用页面截图或预览缩略图代替。
- 下载后复制到 `_工作文件/生成过程/分镜候选.png`。

遇到登录、验证码、二次验证或安全确认时必须暂停，由用户处理；不得索取、读取、记录或转发用户账号密码。

ChatGPT 不可用、达到使用限制、生成失败、无法下载原图或图片验收不合格时，进入第三方 API。

## 3. 第三方 API 生图

仅可调用启动确认单中已经配置并获得用户授权的第三方生图 API：

- 正式调用前必须完成 dry-run。
- 必须记录 API 名称、模型、请求参数、请求哈希、任务 ID、费用和响应。
- 付费调用必须在用户确认的预算范围内。
- API 密钥只能从本机环境变量或受保护配置读取，不得要求用户在聊天中粘贴完整密钥。
- 返回图片必须下载到 `_工作文件/生成过程/分镜候选.png`。

第三方 API 未配置、鉴权失败、预算不足或生成结果仍不合格时，暂停当前项目并标记"需要人工处理"；批次中的其他项目继续。

## 尝试次数

每条分镜最多产生三个有效候选：

- 第一次：本机 Codex
- 第二次：ChatGPT 网页端
- 第三次：第三方 API

界面无法打开、登录失效、接口鉴权失败等未实际产生图片的技术失败不计入有效候选次数，但必须立即进入下一路由，不得在同一路由无限重试。

第三个候选仍不合格时，不得继续产生付费任务。

## 统一验收

无论图片由哪个渠道生成，都必须执行相同检查：

- 文件真实存在且可以解码；
- PNG 或允许的目标格式；
- 实际尺寸为 `2160×3840`；
- 画幅为 `9:16`；
- 产品结构、颜色和 Logo 与参考图一致；
- 人物身份、数量、动作和场景符合内容契约；
- 构图满足视频首帧要求；
- 计算并记录 SHA-256。

技术检查或自动视觉检查通过不能代替用户验收。只有用户针对当前候选明确通过，并绑定候选路径和 SHA-256 后，才能晋升为一级 `分镜图.png`。
