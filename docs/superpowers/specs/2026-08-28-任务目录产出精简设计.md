# 产品视频任务目录产出精简设计

## 目标

产品视频单条任务目录的第一级只展示用户日常需要查看和发布的最终产出，避免查询记录、提交请求、实验帧、音轨和历史版本混杂在同一层级。

## 第一级固定产出

单条任务目录第一级最多保留以下五个固定名称的文件：

- `视频.mp4`
- `封面图.png`
- `发布正文.md`
- `标题.txt`
- `分镜图.png`

尚未生成的产出可以缺少，不创建空占位文件。除 `_工作文件` 目录外，其他文件和目录不得留在第一级。

## 工作文件结构

其余文件按用途放入 `_工作文件`：

```text
单条任务目录/
├─ 视频.mp4
├─ 封面图.png
├─ 发布正文.md
├─ 标题.txt
├─ 分镜图.png
└─ _工作文件/
   ├─ 任务状态/
   ├─ 生成过程/
   ├─ 验收记录/
   └─ 历史版本/
```

分类规则如下：

- `任务状态/`：`任务信息.json`、查询结果、查询日志、提交请求、提交预览、提交日志、AutoDL 响应和其他用于恢复任务或防止重复提交的状态文件。
- `生成过程/`：策划内容、分镜提示词、视频提示词、封面标题、口播音轨、口播片段、语音转写、实验帧、首尾帧、预览图及生成过程中的辅助文件。
- `验收记录/`：自动验收报告、人工验收反馈、人工验收结果、人工处理说明和候选经验。
- `历史版本/`：原 `视频版本`、`失败版本` 目录以及非最终视频、封面和其他历史尝试版本。

不能明确分类的非交付文件默认放入 `_工作文件/生成过程/`，不得删除。

## 新任务行为

工作流初始化单条任务时立即创建四个工作子目录。此后的确定性脚本和技能规则直接把过程文件写入对应目录，不先写入第一级再清理。

需要读取任务信息、自动验收报告或其他过程文件的命令统一通过目录协议定位。批次验收报告继续引用第一级五项产出，不受内部归档影响。

任务防重、恢复、轮询和验收逻辑必须继续正常工作；路径变化不能造成 `task_id` 丢失、相同请求重复付费提交或历史版本覆盖。

## 现有任务迁移

为已有单条任务提供可重复执行的整理命令：

1. 只处理用户明确指定的单条任务目录或批次目录。
2. 先建立迁移清单，按分类规则计算目标路径。
3. 若目标不存在，移动源文件。
4. 若目标存在且内容完全相同，保留目标并把源文件记录为重复项，不直接删除。
5. 若目标存在但内容不同，停止该文件的迁移并报告冲突，不覆盖任何一方。
6. 迁移完成后检查第一级只含五项交付物和 `_工作文件`。

本次示例任务使用同一迁移能力整理：

`Y:\0-AI训练\光合视频\轻便侠218 产品图片\生成视频\20260827_批次001\V001_自研3.0防翻系统_乘坐行驶稳_待生成`

## 兼容性

批次级文件（启动确认单、批次任务表、批次汇总和批次验收报告）仍保留在批次目录第一级，本设计只改变单条 `V001_...` 等任务目录。

为兼容未迁移的旧任务，读取逻辑优先读取新路径；新路径不存在时回退到旧的第一级路径。写入逻辑只使用新路径。迁移完成并验证后，可以在未来版本中移除旧路径回退。

## 验证标准

- 新建任务的第一级除 `_工作文件` 外不预先创建过程目录或状态文件。
- 内容落盘后，五项最终产出按约定留在第一级，过程文件进入正确分类。
- 记录 `task_id` 后，项目状态和批次任务表同步成功。
- 批次验收报告能展示第一级的视频、封面和标题，并读取新路径中的状态与验收摘要。
- 对旧目录执行迁移两次，第二次不产生额外移动或覆盖。
- 迁移遇到同名异内容文件时明确报错，文件保持不变。
- 示例任务整理后，第一级只包含现有五项交付物和 `_工作文件`。

## 不在本次范围

- 不删除任何已有文件。
- 不调整批次目录的一级文件结构。
- 不修改视频内容、封面内容、文案或已保存的任务标识。
- 不重新提交任何付费视频任务。
