# 验收、反馈与学习

## 自动模式

自动生产模式的 V01 不存在语义审核关卡。确定性技术检查（文件存在、完整解码、时长/比例、有效音轨、请求/候选 SHA-256 绑定）通过后，运行器自动交付 `V01_DELIVERED` 并进入 `WAITING_USER_FEEDBACK`。自动检查只形成技术证据，不能替代或伪装成人对语义质量的判断。

交付后向用户展示真实存在的绝对路径、SHA-256、时长、分辨率与成本。用户未反馈时不自动重做、不自动 V02、不自动评价 V01。用户反馈后才允许 `request-rerun` 记录原因；随后单独询问并取得 V02 显式费用批准。V02 走人工验收，V02 后不允许 V03。

## 学习确认模式

学习确认模式维持 `USER_FINAL_REVIEW_REQUIRED`。用户根据候选、时间点和技术证据作出通过/不通过结论，`complete-review` 把明确结论和 SHA-256 绑定。用户明确通过优先于自动检查结论；若需更正，追加新的 `passed` 或 `failed` 事件，不改写历史。

## 反馈记录

反馈记录包含视频 ID、版本、候选绝对路径、哈希、时间点、用户原话和可复现现象。自然视角变化、轻微亮度波动不单独自动判为硬失败；切镜、持续人物裁切、产品与参考图不一致、台词重复、非说话者发声、清单外人声、尾句被截断等由用户反馈或技术合同定位。

## 人工反馈定位知识（不得注入生成提示词）

人工反馈可引用产品参考图和候选视频进行诊断，但任何产品外观、组件、颜色、形状或结构结论都不得写入下一次的生成提示词。下一次 V02 仍只使用产品参考图作为唯一产品依据。
