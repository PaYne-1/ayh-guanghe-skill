# 轻便侠218 多图测试口播修正设计

## 目标

在保留用户认可的连续运镜与整体表现方式的前提下，解决开场问题“爸，菜市场地湿，会打滑吗？”重复出现的问题，并改善后半段陪护者出框。

## 已确认方案

采用方案 A：继续使用模型原生双角色对白，不增加独立参考音频，不改变三句既定台词。

## 提示词修改

1. 给三句台词划分不重叠的唯一时间段：
   - 0–3 秒：P2 儿子只说一次开场问题。
   - 3–8 秒：P1 老人只说一次卖点回答。
   - 8–15 秒：P1 老人只说一次下单引导。
2. 明确禁止任何台词重复、复述、回声、同义改写或新增。
3. 开场问题结束后，P2 不得再次说话；P1 不得代替 P2 重复问题。
4. 保留连续、自然、缓慢的运镜表现，允许轻微平稳推近。
5. 推近过程中始终动态保持 P1、P2 和完整轮椅在安全画框内；陪护者后半段不得出框。

## 验收标准

- 开场问题及其同义表达全片只出现一次。
- 三句台词按 P2、P1、P1 的顺序各出现一次，无漏句或新增。
- 对话衔接自然，无超过 1.2 秒的异常长停顿。
- 全片不切镜、不跳切、不突然改变景别。
- 允许连续缓慢推近，但老人、陪护者和完整轮椅始终入镜。
- 最终仍由用户观看和试听全片后决定是否通过。

## 安全边界

生成修正版提示词本身不联网、不扣费。后续如需再次提交，必须重新展示工作流、预算和本次预计费用，并取得用户明确付费确认。
