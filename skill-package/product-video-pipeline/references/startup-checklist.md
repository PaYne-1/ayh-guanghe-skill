# 任务启动确认单

## API 前置规则

安装后首次使用技能时，第一步必须询问 AutoDL API 是否已接入。API 未接入时，只提供安全配置指导并暂停，不得询问产品参数、扫描产品图片、创建批次或调用付费接口。不得要求用户把完整 API Key 粘贴到聊天中。

API 接入后，先完成不联网、不扣费的 dry-run。只有 API 配置可用，才展示下方任务启动确认单。API 就绪不代表已获准付费，正式提交仍需单独确认价格和预算。

正式执行前，把以下内容一次性展示给用户并获得确认。未确认时可以扫描、规划和 dry-run，不得调用付费视频接口。

## 运行中不再补问

确认后，不要在中间节点才询问文本模型、生图模型、配音、分辨率、普通重试次数或预算。以下情况可以暂停：

- 学习模式预先约定的策划与分镜审核；
- API 整体鉴权失效、余额不足、预算即将超限或必要配置失效；
- 批次结束后的人工视频验收；
- 学习模式重跑前的统一修改方案和费用确认。

实时价格只在任务开始时记录。技能包不把历史截图价格当作永久报价。
