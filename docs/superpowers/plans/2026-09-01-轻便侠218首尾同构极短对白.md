# 轻便侠218首尾同构极短对白执行计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成一次 MiniMax-H3 首尾同构锁镜与极短原生双人对白的最终付费验证，并形成可审计的人工验收与能力边界记录。

**Architecture:** 以已通过的正式首帧为不可变起点，先生成同机位、同景别的新尾帧并单独验收，再生成只含两句对白的单状态视频提示词。所有请求先执行本地 dry-run 和实时价格检查，取得明确付费确认后才提交；最终用场景突变、静音、逐秒抽帧和人工试听共同验收。

**Tech Stack:** Codex ImageGen、Python 3、AutoDL.Art ComfyUI API、MiniMax-H3 `minimax_h3_lightx2v`、FFmpeg/FFprobe、product-video-pipeline 脚本。

## Global Constraints

- 必须纯 AI，只使用 MiniMax-H3，保留模型原生双人对白。
- 视频固定 15 秒、768P 竖屏、无独立配音、无后期换音。
- 原始正式首帧不得修改；新尾帧必须独立生成、单独通过并拥有不同 SHA-256。
- 老人全身、儿子全身和整台轻便侠218必须在首尾端点及全片完整入镜。
- 本方案是最后一次付费验证；失败后停止继续重试。
- 学习模式每一步都需要用户明确确认。
