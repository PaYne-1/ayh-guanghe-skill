# 任务启动确认单

## 每次任务的首次沟通

### 任务窗口路由

只有明确触发词 `开始产品视频`、`制作产品视频`、`生成产品视频`、`电动轮椅视频`、`光合视频任务`、`继续产品视频任务` 或显式调用技能时，才启动产品视频确认流程。新窗口中的“你好”、普通“继续”、一般视频讨论或其他泛化消息不触发清单。

已有产品视频任务窗口中的普通消息继续当前任务，不重新展示清单。用户明确表示换产品或新批次时，只问一次“是否开始全新的产品视频任务？”；回答“是”后才展示新任务清单，回答“否”则继续当前任务。新任务不得继承上一任务的预算、付费授权或自动执行授权。

明确触发任务后，第一步向用户展示完整三段式沟通清单。即使产品路径或历史配置已经存在，也要带入已有字段并取得本次任务回复。

首次清单只使用对话中已经出现的信息，不读取密钥、不扫描文件夹、不初始化批次、不联网查询价格、不生图、不运行 dry-run。每项标记为 `已提供`、`待确认` 或 `需要提供`。未收到用户明确回复前，不扫描产品素材，也不执行任何生产节点。

### 你需要提供的内容

```text
产品文件夹：[已提供：路径 / 需要提供]
产品名称：[已提供：名称 / 待确认：根据文件夹识别]
本次卖点：[已提供：逐条列出 / 需要提供]
视频总数：[已提供：数量 / 需要提供]
封面参考文件夹：[已提供：路径 / 需要提供]

第三方生图 API：[已提供：名称与安全环境变量状态 / 待确认 / 不使用]
```

首次清单不询问 AutoDL API 接入状态或鉴权方式。回复后验证时直接读取安全环境；`AUTODL_AUTH_SCHEME` 缺省按 `bearer`。只有缺少 `AUTODL_API_KEY`，或实际鉴权失败并阻断流程时，才询问并引导安全配置。不得要求用户在聊天中粘贴完整 API Key。

## 运行中不再补问

自动生产模式不再逐节点询问“确认”或“继续”：启动与付费授权完成后，内容、分镜、尾帧、封面、正文和标签连续执行到最终视频验收。确认后也不要在中间节点补问文本模型、生图模型、配音、分辨率、普通技术重试或预算。以下情况必须或可以暂停：

- 学习模式预先约定的策划与分镜审核；
- API 整体鉴权失效、余额不足、预算即将超限或必要配置失效；
- 批次结束后的人工视频验收；
- 任一模式下视频验收失败后的重跑决定；即使自动生产模式也必须先反馈并取得明确重跑授权。

实时价格只在任务开始时记录。技能包不把历史截图价格当作永久报价。
