# 任务启动确认单

## 每次任务的首次沟通

每次任务开始时，第一步必须先向用户展示完整的三段式沟通清单。即使 API、产品路径或以前的配置已经存在，也必须再次展示全部字段并取得本次任务的明确回复，不得直接沿用后开始执行。

首次清单只使用对话中已经出现的信息，不读取密钥、不扫描文件夹、不初始化批次、不联网查询价格、不生图、不运行 dry-run。每项标记为 `已提供`、`待确认` 或 `需要提供`。未收到用户明确回复前，不扫描产品素材，也不执行任何生产节点。

### 你需要提供的内容

```text
产品文件夹：[已提供：路径 / 需要提供]
产品名称：[已提供：名称 / 待确认：根据文件夹识别]
本次卖点：[已提供：逐条列出 / 需要提供]
视频总数：[已提供：数量 / 需要提供]
封面参考文件夹：[已提供：路径 / 需要提供]
AutoDL API：[已提供：已通过安全环境变量接入 / 待确认：是否已接入]
AutoDL 鉴权方式：[已提供：bearer 或 raw / 待确认]
文本生成能力：[已提供：当前 Agent 原生或 API 配置 / 待确认]
第三方生图 API：[已提供：名称与安全环境变量状态 / 待确认 / 不使用]
```

不得要求用户在聊天中粘贴完整 API Key，只询问是否已通过环境变量或平台密钥管理接入。

## 运行中不再补问

确认后，不要在中间节点才询问文本模型、生图模型、配音、分辨率、普通重试次数或预算。以下情况可以暂停：

- 学习模式预先约定的策划与分镜审核；
- API 整体鉴权失效、余额不足、预算即将超限或必要配置失效；
- 批次结束后的人工视频验收；
- 学习模式重跑前的统一修改方案和费用确认。

实时价格只在任务开始时记录。技能包不把历史截图价格当作永久报价。
