# 视频单镜头与完整口播规则设计

## 目标

为产品短视频建立可执行的硬规则：15秒视频必须一镜到底，以缓慢、连续、平稳的方式运镜，并在自然聊天语速下完整说完全部口播。规则同时约束策划、提交提示词、自动验收和反馈重跑。

## 画面连续性合同

- 全片只能使用一个连续镜头，禁止切镜、跳切、转场、突然推近、突然拉远和景别突变。
- 允许摄影机缓慢、连续、平稳移动，但运镜过程中必须保持已通过分镜的人物完整度、轮椅角度、主体构图、曝光、白平衡、亮度和色温。
- 人物不得在中段出框或只剩身体局部；产品主体不得因运镜被遮挡、裁切或改变展示角度。
- 任一时刻发生切镜、明显重新构图、人物出框或产品角度明显改变，自动判为视频不合格。

## 口播完整性合同

- 口播必须按自然聊天语速完整结束，禁止加速抢读、漏词、改词或截断尾句。
- 提交前必须估算台词时长。预计无法在15秒内自然说完时，系统自动精简台词。
- 精简必须保留三项内容：本条唯一卖点、用户使用改善、结尾了解引导；不得新增未经提供的参数或承诺。
- 精简后重新估算，只有确认能在15秒内自然说完才允许付费提交。
- 生成后通过音轨或语音转写核对口播；缺少任一关键内容、尾句未完成或语速明显不自然，自动判为不合格。

## 执行位置

1. 策划阶段：生成15秒台词并执行时长预检，必要时自动精简。
2. 提示词阶段：写入“一镜到底、缓慢连续运镜、禁止切镜、口播完整结束”的明确约束。
3. 验收阶段：同时检查首中尾画面连续性、人物与产品一致性，以及语音转写完整性。
4. 重跑阶段：只针对已识别的失败项强化提示词；继续遵守原有预算、重跑次数和付费确认规则。

## 验收输出

自动验收报告必须分别给出：

- 单镜头连续性：通过或不通过，并标注异常时间点。
- 运镜稳定性：通过或不通过，并说明人物、产品或构图是否漂移。
- 口播完整性：通过或不通过，列出缺失、改写或截断内容。
- 最终判定：任一硬规则不通过，则整条视频不通过。

## 测试范围

- 规则文档必须包含单镜头、平稳连续运镜和完整口播要求。
- 内容校验应拒绝未声明单镜头约束的视频提示词。
- 自动验收规范必须把切镜、构图漂移和口播截断列为硬失败项。
- 技能源码副本与已安装副本必须保持一致。

## 非目标

- 不开发视频生成应用或新的可视化界面。
- 不改变15秒时长、默认分辨率、预算或付费授权规则。
- 不承诺模型绝对服从提示词；规则负责提交前预防、生成后识别和阻止不合格结果进入交付。
