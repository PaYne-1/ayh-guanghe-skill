# 产品视频生图渠道启动选择设计

日期：2026-09-09

## 目标

产品视频任务启动时必须让用户在 `GPT 网页端` 与 `第三方 API` 之间选择生图渠道。选择写入批次状态和批准清单后，分镜、尾帧、封面在整个批次中固定使用该渠道。未选择时不得进入内容生产或生图阶段。

## 启动交互

启动确认单的“你需要提供的内容”和“本次配置明细”必须展示生图渠道选择：

- `GPT 网页端`：使用用户当前已登录的 ChatGPT 网页会话。
- `第三方 API`：同时要求 API 名称、`base_url`、模型、密钥环境变量名、单张价格和本批次图片总预算。

渠道没有默认值。用户未明确选择时，批次停留在启动确认阶段；不得创建付费任务、调用图片服务或自动代选。

## 批次锁定与失败处理

批准启动时，运行器把渠道、批次视频清单及相关配置写入不可变的批准清单。后续恢复必须复用同一渠道。

- 不允许在分镜、尾帧、封面之间改变渠道。
- 不允许渠道失败后静默切换备用渠道。
- 需要改变渠道时，必须结束当前批准范围并重新进行启动配置与预算确认。
- 单条技术失败仍按现有逐项失败策略处理，批次内其他条目继续；不得借失败扩大付费授权。

## 运行器动作

状态机根据已批准渠道返回且只返回一种生图动作：

- `gpt_web` → `GPT_WEB_IMAGE_REQUIRED`
- `third_party_api` → `THIRD_PARTY_IMAGE_REQUIRED`

两种动作都包含唯一 `action_id`、视频 ID、产物名、提示词路径、参考图路径和目标用途。第三方 API 动作额外包含已批准的非敏感接口配置及单次预算上限；只引用密钥环境变量名，不输出密钥值。

结果统一通过 `accept-image` 接收。动作预留、幂等回执、失败计数和恢复规则沿用现有状态机；供应商调用不能绕过动作预留。

## 费用边界

第三方图片 API 费用与 DeepSeek 文本费用、AutoDL 视频费用分账：

- 启动时批准图片单价和图片总预算。
- 每个 API 生图动作在返回前预约一次预计费用。
- 同一 `action_id` 重复读取或重复接收结果不重复计费。
- 预算不足时不返回新的第三方 API 生图动作。
- GPT 网页端不写入第三方 API 费用账本。

## 图片验收策略

无论选择哪种渠道，都不进行人工图片审核，也不调用模型做二次视觉审核。下载结果只执行已有的免费确定性检查：文件存在且可解码、9:16、允许的等比归一化、原图与结果 SHA-256、尾帧与首帧哈希不同。通过后自动晋升并进入下一步。

## 安全与配置

- 不在聊天、状态 JSON、日志或发布包中保存 API 密钥。
- 第三方 API 调用只从已批准的环境变量读取密钥。
- `base_url`、模型和价格变更会使原批准清单失效。
- 未知提交状态必须保留请求身份并停止自动重提，防止重复扣费。

## 测试要求

1. 启动未选择渠道时必须失败关闭。
2. 两种渠道分别返回正确且唯一的外部动作。
3. 批次运行中不能切换渠道。
4. 第三方 API 缺少配置、密钥或预算时不得产生调用动作。
5. 第三方 API 预算预约、幂等回执和失败恢复不能重复计费。
6. 两种渠道的图片结果都走相同的本地技术检查与自动晋升。
7. 技能文档、启动确认单、策略、自检和发布包不得再声称 GPT 网页端是唯一渠道。
8. 全部测试只使用离线桩，不执行真实网页生图或付费 API 调用。

## 不在本次范围

- 不实现渠道之间的自动故障切换。
- 不增加逐张图片的渠道选择。
- 不改变 DeepSeek 文本调用预算、AutoDL V01/V02 授权或最终视频人工验收规则。
