# 多图全景口播模板

适用于当前15秒多图参考工作流。目标是连续全景中完成双人对话，产品全貌和两个人物全身始终在画面内。保留固定机位意图，不宣称API硬锁镜头或硬锁首尾帧。用户接受一条有自然视角变化的视频，不等于所有新任务可以随意运镜。

## 策划输入

新策划写入`video_prompt_style: reference_wide_v1`。`video_prompt`只写简短场景、已有的必需短语与确认过的动作，不粘贴台词、说话说明或成串否定要求。产品参考图仍是唯一产品依据，不描述或重构产品部件。

`people`可增加`video_role`和`video_voice`，由助手根据当前参考与用户信息填写简洁英文身份/位置、自然普通话声线；不能从旧批次猜测左右位置或性别，不确定性别时用中性描述。缺省时使用现有identity和中性普通话描述，不阻断启动。

```json
{
  "video_prompt_style": "reference_wide_v1",
  "video_prompt": "一镜到底，固定机位，完整双人对话口播。保持参考图场景。",
  "people": [
    {"id": "P1", "identity": "老人", "video_role": "The elderly rider", "video_voice": "a warm older Mandarin voice"},
    {"id": "P2", "identity": "陪护者", "video_role": "The companion", "video_voice": "a clear natural Mandarin voice"}
  ]
}
```

示例只是策划片段，其余字段仍按内容契约填写。轮椅移动不是默认动作；只有绑定当前分镜哈希的用户动作确认才允许，运动范围保持在全景安全区。

## 编译后的结构

1. 两张图是同一场景的构图参考；第一张提供布局，第二张加强一致性。不要把参考图字段当作硬端点。
2. 一个连续15秒的远距离全景：完整产品与人物四周留余量，说话交接不改变景别，参考场景/身份/服装一致。
3. 每句只有一个`<d>[Chinese]实际台词</d>`。同一行先写另一人闭嘴听，再写本句说话人的身份、固定S编号和台词。说明全部位于标签外，不使用“依次只说下列三句”等口播式元指令。
4. 交接与片尾保留至少0.4秒闭嘴静默；无额外人声、旁白或BGM。原台词、时序、角色在单变量构图/种子试验中保持不变。

编译器先校验原始内容安全与动作授权，再生成规范文本；提交前精确重编译比较，不仅搜索必需短语。软件校验只能验证指令结构，不代表生成画面或声音合格。

## 种子和对照

运行器按批次及尝试编号确定种子，同一尝试准备/轮询/下载必须稳定复用，不在每次运行时随机更换。经用户明确授权的新尝试可以换种子并记录旧值、新值、请求哈希和视频哈希；单变量测试必须确认除seed外所有实际请求字段相同。不能修改已提交请求、冒用原task_id，或自动连续试种子扣费。

成功种子只对具体参考图、提示词、工作流与参数组合提供复现线索，不是所有产品的全局最佳种子；不要硬编码本次成功值到新批次。

## 验收与学习边界

保留技术检查、口播反馈、产品完整入画和固定机位四类结论。抽样出现裁切即可记录失败；逐秒抽样无异常只能报告抽样结果，不能伪装逐帧通过。用户认可的成片保存原话和SHA256，不伪造助手试听结论。新场景使用此结构仍需结果验证，不把单次用户接受提升为模型稳定性保证。原有付费授权和300/60秒轮询规则保持不变。
