# 分镜图生成渠道

## 用户选择

开始新批次时，必须把以下三个平级选项交给用户选择：

- 本机 Codex 界面（`codex`）
- ChatGPT 网页端（`chatgpt_web`）
- 已配置并获准使用的第三方生图 API（`third_party_api`）

不得设置默认渠道、固定优先级或自动降级顺序。用户选定后，本批次内锁定该渠道；渠道不可用时暂停当前项目并说明原因，不得擅自换渠道。

## 本机 Codex 界面

使用独立生图任务，上传产品参考图并提交完整提示词、`2160×3840` 和 `9:16` 要求。必须取得实际原始图片文件，界面预览或截图不算完成。

## ChatGPT 网页端

使用本机已登录的独立 ChatGPT 对话，上传相同参考图并下载原始图片。遇到登录、验证码、二次验证或安全确认时暂停，由用户处理；不得读取、记录或转发账号密码。

## 第三方 API

只调用启动确认单中已经封存并获得授权的 API 配置。请求、成本和结果进入图片台账；API Key 只能从环境变量读取，不得写入启动 JSON、命令行、日志或聊天。

## 统一技术要求

无论选择哪个渠道，分镜、尾帧和封面都必须满足同一合同：

- 产品参考图是唯一产品依据；
- 文件真实存在、可解码并记录 SHA-256；
- 原生尺寸为 `2160×3840`，画幅 `9:16`；
- 禁止本地放大、拉伸、裁切、补画或重绘；
- 图片动作只通过 `accept-image` 回传并接受确定性技术检查。

自动 V01 不增加人工图片审核或模型视觉审核。用户提出反馈后，才进入显式 V02 流程。
